# The Hive: what an operator can verify

Start at **Shift control → Needs attention → Decision readiness**. Read the cause, who owns the next step, and what evidence is missing. For a running attempt, open **Rails timeline → Inspect history**. A change there prompts investigation; the overview count changes only after the collector confirms it. See the [operator guide](https://github.com/mojomast/orbitdesktop/blob/bcaddc960561558dc9d71887354a54d777312491/docs/HIVE_MISSION_CONTROL.md), the [review gallery](http://100.72.41.9:35853/nightshift/mission-control/) on Tailscale, and the [exact evaluation profile](hive-candidate.json).
