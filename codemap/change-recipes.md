# Change recipes: "to do X, touch Y"

Per-repo recipes are in each `codemap/L1/<repo>.md`. These are the ones that cross repos. Order matters: protocol first, then server, then clients, then UI.

| To… | Touch, in order | Then check |
|---|---|---|
| Add a hyvv `/v1` endpoint | `hyvv/contract/v1/openapi.yaml` + `hyvv/contract/v1/schemas` → `hyvv/contract/v1/reference.py` + conformance tests → `hyvv/launcher.py` `make_handler` → `hyvv/contract/v1/STATUS.json` (`python -m contract.v1.status --write`) → clients `bundlebees/bundlebees_plugin/client.py`, `orbitdesktop/server/local-workers.mjs` | additive only; no client may assume a reference-only route is live |
| Add a field to a brief | `hyvv/brief.schema.json` (host side) and `bundlebees/bundlebees_plugin/brief.py` (coordinator side); if it is protocol, `workflow/docs` + a schema in `workflow/schemas` | unknown fields fail closed; update `bundlebees/scripts/measure_schemas.py` budget if tool schemas grow |
| Add an attempt state | `hyvv/launcher.py` → `orbitdesktop/server/local-workers.mjs` (`TERMINAL`, column map) → `orbit-control-plane/src/columns.mjs` + `orbit-control-plane/src/ingest.mjs` → `orbit-control-plane/src/observability.mjs` buckets | states must agree in all four places |
| Add or bump a protocol document (`acdd`, RETURN, recovery, packet…) | `workflow/schemas` + example + checker in `workflow/tools` + CI job → bundlebees module (`contract.py`, `return_report.py`, `recovery.py`, `packets.py`) → orbitdesktop evidence view if shown | new id (`/2`) for breaking changes; keep reading `/1` until migrated |
| Change the Rails ledger | wire format `workflow/schemas/rails` (frozen; needs a new version) → runtime `bundlebees/contrib/rizzstack_rails` → re-vendor into `hyvv/contrib/rizzstack_rails` and `orbitdesktop/contrib/rizzstack_rails` → producers `hyvv/rails_emitter.py`, consumers `bundlebees/bundlebees_plugin/rails_remote_source.py`, `orbitdesktop/server/rails-proxy.mjs` | vendor checks in hyvv and orbitdesktop CI |
| Add a live-observability metric to Hermes chat | `orbit-control-plane/src/obs-collect.mjs` (collect) → `orbit-control-plane/src/observability.mjs` (allow-list + `sanitizeText`) → `orbit-control-plane/hermes-plugin/rizzobs/rizzobs_plugin/snapshot.py` (coerce) → `orbit-control-plane/hermes-plugin/rizzobs/rizzobs_plugin/cards.py` (render) | card ≤100 components, no actions; uirizz untouched |
| Add an Observatory panel | `workflow/observability/schemas` → `workflow/contrib/rizzstack-observability/collector.py` → `workflow/apps/rizzstack-observatory` and `orbitdesktop/apps/rizzstack-observatory` | `observability` job in workflow CI |
| Add a new worker backend (not Cua) | implement the adapter contract in `bundlebees/docs/ADAPTERS.md` in `bundlebees/bundlebees_plugin/adapters.py`, or make the backend speak hyvv `/v1` | coordinator must not learn backend internals |
| Add a model/provider | host routing in `hyvv/launcher.py` (`model_spec`) + `hyvv/config.example.json`; route preview in bundlebees (`bundlebees_route_preview` in `bundlebees/bundlebees_plugin/tools.py`); provider attribution in `orbit-control-plane/src/obs-collect.mjs` | keys stay on the host; named model is authoritative |
| Add a risk-sensitive path | path floor in `bundlebees/bundlebees_plugin/risk.py` and `bundlebees/bundlebees_plugin/policy/risk-floor.json` (the tier → process table is parked, unwired, in `bundlebees/contrib/unwired/risk_policy.py`) | high tier requires a frozen `acdd/1` contract |
| Change the merge gate (lease/tamper, risk tier T1/T3, always-T3) | `.github/scripts/lease_tamper.py` in this repo + `tests/test_risk_tier.py` and `.github/scripts/gate_drill.py` cases; then copy byte-identically to `workflow/.github/scripts/lease_tamper.py`, `hyvv/.github/scripts/lease_tamper.py`, `bundlebees/.github/scripts/lease_tamper.py`, `orbitdesktop/.github/scripts/lease_tamper.py`, `orbit-control-plane/.github/scripts/lease_tamper.py`, `uirizz/.github/scripts/lease_tamper.py` and update the lane's pinned script sha | owner + outside review; never pre-authorizable |
| Deploy the hyvv launcher | `hyvv/scripts/launcher-admin.ps1` (`apply-update`), payload from the built wheel via `hyvv/scripts/deploy_payload.py`, health wait in `hyvv/scripts/start.ps1` | owner's typed yes; build-sha proof, pre-restart smoke, automatic revert |
| Review a pull request | `skills/rizzstack-outside-review/SKILL.md` (reviewer) and `policy/outside-review.md` (coordinator) | reviewer model family differs from every author family |
| Add an A2UI component | only if in the official Basic Catalog: `uirizz/uirizz_plugin/catalog.py` + `uirizz/uirizz_plugin/validate.py` + `uirizz/desktop/src/card.jsx` | token budgets; no Progress/Chart/Table in the catalog |
| Add a CI gate to every repo | each repo's `.github/workflows`; pin actions by full SHA like the existing workflows; `permissions: contents: read` | gitleaks before push; never weaken an existing gate to get green |
| Update this map after upstream merges | bump `sha` in `scripts/codemap/sources.json` → `python3 scripts/codemap/build.py` → fix any `--verify-docs` failures in hand-written files | `python3 scripts/codemap/build.py --check` |
